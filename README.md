# 비상장 종목 서치 대시보드

비상장 기업을 발굴하기 위한 대시보드입니다.

## 데이터 소스
- **네이버 뉴스 키워드**: "IPO 지정감사", "상장 주관사선정", "프리IPO", "VC 투자유치" 등 키워드로 기사 수집 → 기업 언급 빈도 집계
- **THE VC (thevc.kr)**: 최근 투자/M&A 내역, 스타트업 투자 라운드 정보
- **거래 플랫폼**: K-OTC / 서울거래소 / 네이버페이 비상장 (수집 예정)

## 데이터 갱신
`update.bat` 실행 → `scripts/fetch_all.py`가 전체 데이터를 수집하고 `data.js`를 생성합니다.

```
python scripts/fetch_all.py
```

## 구성
- `index.html` — 대시보드 (정적 페이지)
- `data.js` — 수집된 데이터 (자동 생성)
- `scripts/` — 데이터 수집 스크립트

데이터는 수집 시점의 스냅샷이며, 뉴스 검색 결과는 시점에 따라 달라집니다.
